# ⚡ BidCraft AI — Upwork & LinkedIn Proposal Generator Chrome Extension

Ye ek complete, production-ready **Google Chrome Extension (Manifest V3)** hai jo freelancers aur agencies ko Upwork par winning proposals aur LinkedIn par high-converting outreach messages likh kar deti hai.

---

## 🚀 Features (Khasosiyat)
1. **Auto-Detect from Upwork & LinkedIn:** Job page par sirf 1-click karne se Job Title, Job Description, aur Screening Questions khud-ba-khud extract ho jate hain.
2. **In-Page Floating Widget:** Upwork aur LinkedIn par direct ek button `⚡ BidCraft AI` show hota hai, jis se page chhore baghair proposal ban jata hai.
3. **Winning Upwork Formula:** AI ko khaas taur par train kiya gaya hai taake wo generic clichés ("Dear Hiring Manager", "I have 5 years experience") na likhe, balkay pehli 2 lines me client ki pain point ko hook kare aur low-friction CTA de.
4. **Multiple Tone & Styles:** 
   - Winning Upwork (Hook + Proof + CTA)
   - Short & Punchy (< 100 words)
   - Senior Consultant
   - Warm LinkedIn Pitch
5. **Saved Freelancer Profiles:** Apni multiple profiles (e.g. Full-Stack Dev, Graphic Designer, SEO Expert) save karein taake bar bar bio na likhni paray.
6. **Quick Refine Pills:** 1-click me proposal ko "Shorter", "Stronger Hook", ya "More Urgent" banayein.
7. **Proposal History:** Pichle proposals local storage me save rehte hain.
8. **100% Free to Run:** Google Gemini 1.5 Flash API use karta hai jo bilkul free hai.

---

## 🛠️ Chrome me Install Karne Ka Tareeqa (Step-by-Step)

1. Apne Google Chrome browser me jayein aur address bar me ye type karein:
   ```
   chrome://extensions
   ```
2. Ooper right corner me **Developer mode** ka toggle switch **ON** karein.
3. Ab ooper left corner me **Load unpacked** button par click karein.
4. File selector me ja kar is folder ko select karein:
   ```
   F:\Upwork LinkedIn Proposal Chrome Extension)
   ```
5. **Mubarak ho!** Extension install ho chuki hai. Chrome ke ooper Extensions icon (puzzle piece) par click karein aur `BidCraft AI` ko **Pin 📌** kar lein.

---

## 🔑 Free Gemini API Key Kaise Hasil Karein (30 Seconds)

1. [Google AI Studio (aistudio.google.com/app/apikey)](https://aistudio.google.com/app/apikey) par jayein.
2. Apne Google Account se sign in karein.
3. **"Create API Key"** par click karein aur key copy kar lein.
4. BidCraft extension k icon par click karein -> **Settings (⚙️)** me jayein -> API key paste karein aur **Save** kar dein.
